# Java & TypeScript Expert - Banking & Ecommerce Curriculum

> Giáo trình 15 ngày: Từ Zero đến Junior Developer

## Tổng quan

Giáo trình thiết kế cho người mới bắt đầu (có kiến thức nền cơ bản về lập trình) để học Java và TypeScript thông qua real projects trong lĩnh vực Banking và Ecommerce.

## Phương pháp học

- **30% Lý thuyết - 70% Thực hành**
- Mỗi ngày 8 tiếng: Ôn bài → Lý thuyết → Bài tập → Thực hành → Mini Project → Review
- Learning by Doing với real-world scenarios

## 3 Phases

| Phase | Ngày | Nội dung | Output |
|-------|------|----------|--------|
| 1 - Nền tảng | 1-5 | Java Core, TypeScript, Git | Console apps |
| 2 - Backend | 6-10 | Spring Boot, JPA, NestJS, Security | REST APIs |
| 3 - Real Project | 11-15 | Banking App + E-Commerce Platform | 2 complete apps |
